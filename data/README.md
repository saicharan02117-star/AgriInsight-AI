# Dataset

Primary dataset: Crop Yield Prediction Dataset

Kaggle source: https://www.kaggle.com/datasets/patelris/crop-yield-prediction-dataset

The application first looks for `yield_df.csv` beside `AgriInsight_AI.py`. If the file is not present, it attempts to load the public mirror documented in the project code and README.

For fully offline execution, download `yield_df.csv` from the dataset source and place it in the project root.
