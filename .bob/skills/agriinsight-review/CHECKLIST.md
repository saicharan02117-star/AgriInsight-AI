# AgriInsight AI Review Checklist

- [ ] Problem statement matches the dataset and dashboard.
- [ ] Required columns are checked before analysis.
- [ ] Missing, duplicate and invalid records are handled transparently.
- [ ] KPIs and charts answer a practical analytical question.
- [ ] Correlation is not described as causation.
- [ ] Baseline and non-linear models are compared.
- [ ] MAE, RMSE and R2 use held-out data.
- [ ] Reliability/uncertainty is shown with predictions.
- [ ] No unsupported agronomic dose recommendations are added.
- [ ] requirements.txt matches imports.
- [ ] README and project report match current code.
- [ ] Required submission files are present.
