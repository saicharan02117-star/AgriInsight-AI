PURPOSE
Use historical crop, climate and agricultural-input data to produce clear KPIs, exploratory data analysis, validated yield prediction and evidence-linked decision-support notes. The project should move from raw data to an understandable decision, not only to charts or a UI.

DATASET
Primary dataset: Crop Yield Prediction Dataset
Source: https://www.kaggle.com/datasets/patelris/crop-yield-prediction-dataset
Main fields: Area, Item, Year, average_rain_fall_mm_per_year, pesticides_tonnes, avg_temp, hg/ha_yield

IBM BOB REVIEW TASKS
1. Confirm the problem statement, KPIs and project scope match the dataset.
2. Review the data-cleaning logic and check that required columns, missing values, duplicates and invalid numeric values are handled transparently.
3. Review EDA and visualizations for crop-level, area-level and time-based trends.
4. Review the machine-learning pipeline: Linear Regression baseline, Random Forest Regressor, one-hot encoding, numeric preprocessing and held-out test split.
5. Verify that MAE, RMSE and R2 are computed from the held-out test set and are not hard-coded.
6. Review the reliability gate and decision-support rules.
7. Check requirements.txt for necessary dependencies and consistency with the code.
8. Check README.md and the project report for consistency with the current project files.
9. Do not invent soil variables, fertilizer doses or pesticide doses that are absent from the dataset.
10. Keep correlation statements exploratory; do not present correlation as causation.
